# task1 个人品牌视觉系统与多平台主页

任务详情: [learn-design/steps/winter/task1.md](https://github.com/west2-online/learn-design/blob/main/steps/winter/task1.md)

## 提交内容

1. 完成个人品牌视觉系统：定位、目标受众、Logo / 头像、配色、字体、图形语言、内容语气与 Identity Token，并说明它和 `term1/task5` 博客的继承或调整关系。
2. 设计并实际发布 GitHub Profile README，清楚呈现个人方向、代表项目或贡献、能力证据与博客 / 作品集入口；至少完成一个体现个人 VI 的可维护自定义模块。
3. 至少完成一个设计社区主页和一个社交平台主页，提交实际页面链接；暂时无法发布的平台需说明限制，并提供按真实平台尺寸完成的 Figma 设计。
4. 说明 Identity Token 与 Platform Mapping：哪些识别规则保持稳定，哪些因受众、尺寸、裁切、简介长度和平台能力调整。
5. 完成未登录、窄屏、深浅色、平台实际裁切与第三方服务失效检查；邀请未参与设计的人完成一次 3 秒识别与入口查找，并依据结果至少迭代一轮。
6. 提交可访问的 Figma 链接：第一个 Page 展示多平台预览、版本和 README 入口，后续 Pages / Sections 保留 Final、Foundations、Components / Assets、References 与 Process；按平台分正式稿，区分 Identity Token 与 Platform Mapping。
7. README 需汇总个人品牌定位、VI 与 Token、平台 Context、GitHub 自定义模块、真实访问测试、修改记录、素材导出方式、授权清单，以及博客与各公开入口的双向衔接。

## 注意

- README 给各平台具体主页、Figma 分区、Profile / 自定义模块源码与本次 Commit；VI、平台规格与规则复查日期、实际发布状态、访问测试和修复记录分别可定位，短内容可合并。
- 实际平台小截图、裁切对照、压缩封面、头像和自定义 SVG 可提交；大原图 / 长录屏 / 复杂工程另存并链接。可沿用改进已有标识与 Token，不要求全部重画。
- 在 README 的“寒假轮面试索引”链接 task2，以及 task3 的至少 3 条发布内容、反馈与 SOP；不创建 task3 个人目录。
- “统一”指稳定的识别规则，不要求把同一张图机械裁切到所有平台；平台实际限制应以提交时的官方规则为准。
- GitHub 的动态服务、Stats 或自定义模块需说明来源、部署、缓存、维护与失败降级；核心身份和链接不能依赖第三方服务才可读。
- 不提交账号凭据、Cookie、未公开个人信息或来源不明的素材；AI 生成或辅助内容同样需要记录模型、时间、来源检查与人工修改。
