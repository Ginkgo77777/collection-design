# task1 个人博客

任务详情: [learn-design/steps/winter/task1.md](https://github.com/west2-online/learn-design/blob/main/steps/winter/task1.md)

## 提交内容

1. 完成个人博客的设计、实现与公网部署，并至少发布一篇文章验证完整发布流程。
2. README 需包括：
   - 可正常访问的博客链接、源码仓库链接，以及可选的 Figma 设计稿链接；
   - Purpose / Audience / Context、内容分区、导航与首页信息层级；
   - 技术选型与理由、项目目录、Design Token、深浅色和响应式策略；
   - 部署方式、维护流程、备份与迁移策略，以及他人如何复用和交接。
3. 提交设计说明与过程记录：参考案例、风格取舍、文章页排版规则、主要修改、响应式与深浅色验收结果。
4. 提交与 Agent 协作的过程记录：关键 Prompt、AI 回复摘要、工具与模型信息、人工修改和验收结论；不要只保留成功结果。
5. 提交发布 SOP，并说明如何通过实际发布的一篇文章验证 `写作 -> 排版 -> 检查 -> 发布` 流程。
6. 提交资产与第三方内容清单，记录字体、图片、图标、模板与代码的来源、授权和修改情况。

> [!NOTE]
> 博客源码应在个人仓库持续维护，本目录提交可审核的说明与过程证据即可，无需复制完整项目。

## 目录规范

```txt
winter/task1
|___ README.md          // 本说明文件
|___ example            // 提交范例(仅作格式参考, 请勿抄袭)
|___ <你的 GitHub ID>   // 你的提交目录
```

个人提交目录建议结构：

```txt
<你的 GitHub ID>
|___ README.md               // 博客/源码/Figma 链接 + 项目总说明 + 验收结论
|___ design
|    |___ design-notes.md    // 定位、信息架构、视觉规则、参考与设计迭代
|___ workflow
|    |___ agent-log.md       // Agent 协作、人工修改与验收记录
|    |___ publishing-sop.md  // 发布、维护、备份与迁移流程
|___ assets
|    |___ LICENSE.md         // 字体/图片/图标/模板/代码来源与授权
|___ preview                 // 可选: 压缩后的关键页面与多端验收预览
```

## 注意

- 链接需开启查看权限并保证面试时仍可访问；预览图不能代替真实网站的多端验收。
- 不提交依赖目录、构建缓存、域名或部署凭据、API Key、Token 与 `.env`。
- 第三方主题与 Agent 生成代码也需记录来源、License 和人工检查结果。
