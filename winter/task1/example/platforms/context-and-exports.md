# 平台 Context 与导出清单(示例)

| 平台 | 受众与目的 | 尺寸 / 格式 | 限制 | 设计适配 | 模板位置 |
| --- | --- | --- | --- | --- | --- |
| GitHub Profile | 查看项目、贡献与技术身份 | Markdown / HTML / SVG，按真实页面检查 | 窄屏、深浅色、外部服务失效 | 先呈现定位与代表项目，再补充自定义 VI 模块 | Figma / Templates / GitHub |
| 设计社区 | 查看完整案例 | 按平台当前规则填写 | 作品封面先于简介 | 强化案例标题与角色 | Figma / Templates / Portfolio |
| 社交平台 | 快速浏览与关注 | 按平台当前规则填写 | 小屏、信息密度高 | 简化图形并突出栏目 | Figma / Templates / Social |

## 导出与发布检查

- 使用平台当前官方规则复核像素尺寸、文件大小、色彩模式和安全区域。
- 检查未登录访问、头像缩略图、深浅色背景、移动端裁切、真实文案与外部服务失效降级。
- 导出文件采用 `<platform>-<asset>-<width>x<height>-v<version>.<format>` 命名。
- 发布前核对文字、双向链接、图片授权和个人信息；修改后记录版本与日期。导出规格在此记录，视觉过程与最终设计仍统一通过 Figma 链接展示。
