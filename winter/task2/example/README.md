## 跨平台衔接摘要

- 固定元素: 头像轮廓、主色语义、标题字体气质与分隔图形。
- 可变元素: 封面比例、信息密度、简介长度和作品排序。
- 与博客衔接: 复用同一组颜色与图形 Token；平台主页负责快速识别，博客负责完整叙事。
- 检查结论: 32 px 头像中细节丢失，因此删除次要线条；深色背景下为标志增加独立的反白版本(示例)。
