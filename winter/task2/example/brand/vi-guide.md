# 个人 VI 规则(示例)

## 基础识别

- Logo / 头像: 说明概念、构造、最小尺寸、安全区、禁用方式与深浅色版本。
- Color: 列出 Primitive 与 Semantic Token、色值、用途和不可用组合。
- Typography: 标题与正文字体、回退字体、授权和平台不支持自定义字体时的策略。
- 图形语言: 说明分隔符、封面网格和装饰图形的复用规则。
