# Three.js 组件说明(示例骨架)

- 在线页面: `https://example-student.example.com/lab/brand-orbit`(示例占位)
- 源码仓库 / Commit: `https://github.com/example-student/brand-orbit/tree/<commit>`(示例占位)
- 用途: 作品集首页装饰；不遮挡内容，并支持减少动态效果。

## 场景与关键参数

| 部分 | 关键参数 | 视觉作用 | 调整依据 |
| --- | --- | --- | --- |
| Camera | 位置、视野角 | 控制构图与透视 | 与首页安全区对齐 |
| Light | 类型、方向、强度 | 建立层级与材质感 | 深浅色分别验收 |
| Material | 颜色、粗糙度等 | 衔接个人 VI | 复用 `winter/task1` 色彩语义 |
