# task2 个人品牌视觉系统

任务详情: [learn-design/steps/winter/task2.md](https://github.com/west2-online/learn-design/blob/main/steps/winter/task2.md)

## 提交内容

1. 完成个人品牌视觉系统：Logo / 头像、配色、字体、图形语言与不同长度的自我介绍，并说明设计理由、使用边界和 Token。
2. 至少完成一个设计社区主页和一个社交平台主页，提供可访问链接或实际页面预览，并记录平台尺寸、格式、简介限制和受众习惯。
3. 说明跨平台策略：哪些识别元素保持统一、哪些因平台 Context 调整，以及它们与 task1 博客如何衔接。
4. 记录小尺寸、大尺寸、深浅色背景和“3 秒识别”检查结果，并列出据此完成的修改。
5. 整理平台素材的导出规格与可复用模板；提交字体、图片、图标等资产的来源、授权和修改情况。

个人提交目录建议结构：

```txt
<你的 GitHub ID>
|___ README.md                    // 定位 + Figma/平台链接 + 与博客的衔接 + 检查结论
|___ brand
|    |___ vi-guide.md             // Logo/头像、颜色、字体、图形语言与 Token
|    |___ profile-copy.md         // 一句话、短简介与长简介
|___ platforms
|    |___ context-and-exports.md  // 平台限制、设计适配、导出规格与模板清单
|___ assets
|    |___ LICENSE.md              // 字体/图片/图标/模板来源与授权
|___ preview                      // 压缩后的跨平台、小尺寸与深浅色预览
```

## 注意

- “统一”指稳定的识别规则，不要求把同一张图机械裁切到所有平台。
- 平台页面与 Figma 链接需开启查看权限；若平台账号不便公开，可提供隐藏个人信息的真实尺寸预览并在面试中展示原页面。
- 不要在本仓库提交账号凭据、Cookie、未公开个人信息或来源不明的素材。
