# task3 内容运营与面试展示

任务详情: [learn-design/steps/winter/task3.md](https://github.com/west2-online/learn-design/blob/main/steps/winter/task3.md)

> [!IMPORTANT]
> 本任务是 `winter/task1` 个人品牌与多平台主页的持续运营延伸，只需要在寒假轮面试中展示与讲解，**无需在本仓库创建个人提交目录或发送单独的作业 PR**。

## 面试证据与记录入口

以下作业记录在个人博客、资产库或项目中持续维护并用于面试展示，不要求复制全文到 `collection-design`：

在 winter/task1 README 的“寒假轮面试索引”给以下材料的主版本链接，可以从 task1 开始积累；只需补充该索引，不新建 task3 个人目录或另发作业 PR。

1. 平台、账号定位、目标受众、内容栏目、发布节奏与衡量目标。
2. 寒假期间实际发布的至少 3 篇 / 条内容，以及素材、草稿、修改和 AI 使用记录。
3. 发布前检查结果：错别字、链接、平台尺寸、深浅色显示与素材授权。
4. 发布后的基础数据与真实反馈，并区分数据、他人反馈和自己的解释。
5. 根据复盘完成的选题或视觉模板调整，及其修改依据。
6. 可复用的封面模板、排版规则、检查清单和内容生产 SOP。

- 内容清单包含平台、日期、主题、具体发布地址；复盘包含观察窗口、数据、匿名反馈、解释与修改；SOP 链接实际模板和授权记录。
- 模板沿用 winter/task1 Figma 的 `Content Templates` Section，无新增视觉时不必新建设计文件。
- 小截图、压缩封面、SVG 模板或轻量图表可放已有记录旁，大视频与原始素材用发布 / 托管链接，反馈先脱敏。
- 至少 3 篇 / 条的基础数量保持不变，之后按精力安排；数据少时写明限制并邀请读者提供理解反馈，不编造数据或以涨粉量验收。

## 面试讲解重点

- 个人品牌如何从博客、跨平台主页、作品集延伸到持续内容运营。
- 哪些内容或视觉策略有效、哪些无效，判断依据是什么。
- 如何降低下一次内容生产成本，同时保留人工判断、版权检查与发布质量。
