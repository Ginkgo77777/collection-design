# task4 内容运营与面试展示

任务详情: [learn-design/steps/winter/task4.md](https://github.com/west2-online/learn-design/blob/main/steps/winter/task4.md)

> [!IMPORTANT]
> 本任务是 `winter/task2` 的自然延伸，只需要在寒假轮面试中展示与讲解，**无需在本仓库创建个人提交目录或发送单独的作业 PR**。

## 建议保留的面试证据

以下内容不要求复制到 `collection-design`，但建议在个人博客、资产库或运营记录中持续维护，以便面试展示：

1. 平台、账号定位、目标受众、内容栏目、发布节奏与衡量目标。
2. 寒假期间实际发布的至少 3 篇/条内容，以及素材、草稿、修改和 AI 使用记录。
3. 发布前检查结果：错别字、链接、平台尺寸、深浅色显示与素材授权。
4. 发布后的基础数据与真实反馈，并区分数据、他人反馈和自己的解释。
5. 根据复盘完成的选题或视觉模板调整，及其修改依据。
6. 可复用的封面模板、排版规则、检查清单和内容生产 SOP。

## 面试讲解重点

- 个人品牌如何从博客、跨平台主页、作品集延伸到持续内容运营。
- 哪些内容或视觉策略有效、哪些无效，判断依据是什么。
- 如何降低下一次内容生产成本，同时保留人工判断、版权检查与发布质量。
