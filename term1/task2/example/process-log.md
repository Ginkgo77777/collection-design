# 设计过程记录

> 流水账式记录, 只记录真实发生的过程, 无需包装成复杂流程

## 09-01 主题确定

- 在三个备选主题(咖啡节 / 天文社 / 电竞赛事)里选了天文社, 因为"夜空"的视觉素材最容易找且授权清晰(星空摄影多为 CC0)
- 决定主色之前先收集了 20 张参考图进 Figma 的 `05_Process` Page / `Reference` Section

## 09-02 草图阶段

- 手绘了两版草图: A 版是"望远镜+星轨"居中构图, B 版是"星空+文字分栏"
- A 版的问题: 标题字会被星轨干扰, 阅读动线绕路; 最终选 B 版
- 草图见 Figma 的 `05_Process` Page / `Draft` Section(评审时可查看)

## 09-05 网格与标题字

- 建立 8px 间距体系, 海报用 12 列网格, 手机尺寸物料用 4 列
- 标题字「星野」以思源黑体为基础改撇捺为星轨弧线, 重做了 3 版, 第 3 版弧线方向统一为左上到右下, 与海报对角线一致
- 遇到的问题: 弧线转曲后字重看起来比原文轻, 解决方式是描边外扩 2px 后再填色

## 09-08 组件库与 Variables

- 把标题、正文、日期卡、二维码框做成了组件; 二维码用占位框, 交付前再换真码
- 用 Variables 管理主色、灰阶与圆角, 中途改过一次主色(从 `#12285E` 改到 `#0E1B3D`), 全局一处修改即可

## 09-10 打印校色

- 打印店试打 A4 小样, 发现星光黄在 CMYK 下偏灰, 最终为打印版单独调了一版黄 `#F7C948`
- 结论: 线上和线下版本的颜色要分开管理, 已记录在 Variables 的说明中

## 09-12 最终取舍

- 舍弃: 门票上的完整星图(信息密度过高, 手持距离看不清), 改为只有一颗主星
- 保留: 四类物料共用同一套"深空蓝底 + 星光黄点缀 + 星轨标题字"的视觉语言
