## Figma Pages / Sections 结构

| 顺序 | Page | 内容 |
| --- | --- | --- |
| 1 | `01_Preview` | 主视觉海报置于首位, 并集中展示四类物料的最终效果 |
| 2 | `02_Final` | 各物料的正式 Frame、实际尺寸、目标媒介与使用方式 |
| 3 | `03_Foundations` | Grid、Spacing、Typography、Color、Radius 与 Variables |
| 4 | `04_Components-Assets` | 组件、图形元素、可编辑艺术字、图片与图标来源说明 |
| 5 | `05_Process` | 参考案例、草图、早期方案、迭代对照、打印校色与最终取舍 |

> Figma 保留完整可编辑设计，首 Page 为预览入口，后续内容可按规模合并为 Sections。README 可附体积合适的整套预览、主视觉或细节图，必要轻量 SVG 也可提交，不要求导出全部画板。

本例选了打印载体，所以需说明生产文件的用途与检查；这不是要求所有同学都做印刷。若提供打印 PDF，列出对应版本、实际尺寸和检查结果；大文件用合适交付空间的链接，网页预览可压缩或转 WebP，生产原件保留质量。未附文件时不能写成已经完成导出或打样。
