# 设计说明: 星野天文社 2026 秋季招新

## Purpose / Audience / Context

- 宣传目标: 在开学季为「星野天文社」招募新成员, 目标招新 60 人
- 目标受众: 2026 级新生为主, 兼顾大二学生; 对天文感兴趣但大多没有专业背景
- 使用场景: 线上(公众号、QQ 群、社团官网)+ 线下(纳新摊位、海报栏)
- 必要限制: 打印物料需控制用色(CMYK 打印校色); 电子屏物料注意深色底在低亮度屏幕下的可读性

## 信息层级

1. 社团名「星野天文社」(最高优先级)
2. 招新标语「来, 把望远镜对准你的第一颗星」
3. 招新时间、地点、报名二维码
4. 社团官方账号

## 项目层统一信息

- 品牌定位: 浪漫、探索、面向零基础
- 风格: 深蓝夜空 + 暖黄星光, 扁平插画风
- 主色: 深空蓝 `#0E1B3D`, 星光黄 `#F5C04E`, 灰阶 `#FFFFFF` / `#A8B2C7` / `#5A6480`
- 正文字体: 思源黑体(可免费商用), 标题字: 自绘艺术字「星野」(见 `assets/title-art.svg`)
- 主视觉标题字选型说明: 现成免费字体缺乏"星轨"的动势, 故以思源黑体为骨架自绘标题字, 在撇捺处加入弧线星轨, 兼顾识别度与主题气质; 标题字保留矢量源文件以便复用于其他物料

## 参考案例分析

| 参考 | 借鉴了什么 | 舍弃了什么 |
| --- | --- | --- |
| NASA 系海报 | 深色夜空 + 高对比星光的氛围 | 摄影写实风格(与本社"零基础"定位不符) |
| 本校往届纳新海报 | 信息层级顺序(社团名 > 标语 > 时间地点) | 多色渐变背景(打印成本高且易脏) |
| 网易云音乐开屏图 | 文字与插画各占一半的版式 | 中心对齐排版(弱化了标题的动势) |
