# task2 平面设计

任务详情: [learn-design/steps/term1/task2.md](https://github.com/west2-online/learn-design/blob/main/steps/term1/task2.md)

## 提交内容

1. 任选主题与场景, 制作包含海报在内的统一主题宣传物料**至少四种**(主视觉海报必做), 同尺寸裁切不算新种类
2. 使用 Figma 完成设计, 并在源文件中展示 Grid、Spacing、Typography、Color、Radius 规则、Variables、Auto Layout 等基础能力
3. 提交物需包括:
   - 至少四种宣传物料, 其中必须包含主视觉海报; 无需向提交仓库提交导出资产, 全部成果统一在 Figma 项目中查看
   - Figma 的**第一个 Page**作为预览入口: 主视觉海报置于最醒目的位置, 并集中展示整套物料的最终效果
   - 后续 Page 有序展示全部正式设计、设计规范、组件与素材元素、参考案例、草图、早期方案、主要修改和最终取舍等设计痕迹
   - Figma 项目中**设计规范的集中展示区**(网格、颜色、字体、间距、圆角等统一变量)
   - 类似日记的**流水账式设计说明与过程记录**(草图或早期方案、参考案例、主要修改和最终取舍)
   - 一份涵盖**可正常访问并具有查看权限的 Figma 链接**的 README, 说明 Figma Page 结构、各物料的使用场景、使用方式、资产来源及授权情况
4. 自绘的艺术字标题需在 Figma 中保留可编辑的矢量结构

```txt
|___ assets               // 本任务使用的字体、图片、图标等资产
     |___ LICENSE.md      // 资产来源与授权清单(原创资产也需注明)
```

## 注意

- 不向提交仓库附加预览图或导出资产, 全部设计效果和可编辑元素均通过 README 中具有查看权限的 Figma 链接查看
- 建议使用 `01_Preview / 02_Final / 03_Foundations / 04_Components-Assets / 05_Process` 等清晰 Page 命名; 第一页位置固定, 后续页可按项目需要调整, 但不得省略过程与元素
- 字体需确认商用授权, 不可用不可商用的字体完成设计
