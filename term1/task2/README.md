# task2 平面设计

任务详情: [learn-design/steps/term1/task2.md](https://github.com/west2-online/learn-design/blob/main/steps/term1/task2.md)

## 提交内容

1. 任选主题与场景, 制作包含海报在内的统一主题宣传物料**至少四种**(主视觉海报必做), 同尺寸裁切不算新种类
2. 使用 Figma 完成设计, 并在源文件中展示 Grid、Spacing、Typography、Color、Radius 规则、Variables、Auto Layout 等基础能力
3. 提交物需包括:
   - 至少四种宣传物料, 其中必须包含主视觉海报；Figma 保留完整可编辑成果，README 可附体积合适的整套预览、主视觉或细节图，不要求导出全部画板
   - Figma 的**第一个 Page**作为预览入口: 主视觉海报置于最醒目的位置, 并集中展示整套物料的最终效果
   - 后续 Pages / Sections 按 Final、Foundations、Components & Assets、References & Process 有序展示正式稿、规范、组件资产与参考过程，不必每个分区独占一页
   - Figma 项目中**设计规范的集中展示区**(网格、颜色、字体、间距、圆角等统一变量)
   - 类似日记的**流水账式设计说明与过程记录**(草图或早期方案、参考案例、主要修改和最终取舍)
   - 一份涵盖**可正常访问并具有查看权限的 Figma 链接**的 README, 说明 Figma Page 结构、各物料的使用场景、使用方式、资产来源及授权情况
4. 自绘的艺术字标题需在 Figma 中保留可编辑的矢量结构

## 注意

- README 给 Figma 首 Page 与主要物料 Frame 的入口、日期 / 版本，以及 design-brief、process-log、授权清单的链接；短文档可合并。过程中的取舍指向具体节点，不重复维护全文。
- 获准分发的轻量 SVG、图标与必要小素材可以提交；预览可压缩或转 WebP，大原图与成套大文件通过合适存储的链接提供。
- 本任务不统一要求印刷交付；实际制作生产文件时说明用途与检查，保留原件质量。示例中的打印场景只是选题示范。
- 建议使用 `01_Preview / 02_Final / 03_Foundations / 04_Components-Assets / 05_Process` 等清晰名称；首 Page 为入口，其余内容可按项目规模分成 Pages / Sections。
- 字体需确认商用授权, 不可用不可商用的字体完成设计
