# task2 平面设计

任务详情: [learn-design/steps/term1/task2.md](https://github.com/west2-online/learn-design/blob/main/steps/term1/task2.md)

## 提交内容

1. 任选主题与场景, 制作包含海报在内的统一主题宣传物料**至少四种**(主视觉海报必做), 同尺寸裁切不算新种类
2. 使用 Figma 完成设计, 并在源文件中展示 Grid、Spacing、Typography、Color、Radius 规则、Variables、Auto Layout 等基础能力
3. 提交物需包括:
   - 至少四种宣传物料的**预览图**与**按实际用途导出的文件**(低保真即可), 其中必须包含主视觉海报
   - Figma 项目中**设计规范的集中展示区**(网格、颜色、字体、间距、圆角等统一变量)
   - 类似日记的**流水账式设计说明与过程记录**(草图或早期方案、参考案例、主要修改和最终取舍)
   - 一份涵盖**可正常访问并具有查看权限的 Figma 链接**的 README, 说明文件结构、各物料的使用场景、使用方式、资产来源及授权情况
4. 自绘的艺术字标题需提交可编辑的矢量源文件

## 目录规范

```txt
term1/task2
|___ README.md          // 本说明文件
|___ example            // 提交范例(仅作格式参考, 请勿抄袭)
|___ <你的 GitHub ID>   // 你的提交目录
```

个人提交目录建议结构:

```txt
<你的 GitHub ID>
|___ README.md            // Figma 链接、文件结构说明、各物料使用场景、资产来源及授权
|___ design-brief.md      // 设计说明: Purpose/Audience/Context、信息层级、风格与字体选型、物料规格、参考案例
|___ process-log.md       // 设计过程记录(流水账): 草图、早期方案、修改与取舍
|___ assets               // 本任务使用的字体、图片、图标等资产
|    |___ LICENSE.md      // 资产来源与授权清单(原创资产也需注明)
|    |___ title-art.svg   // 自绘艺术字标题的可编辑矢量源文件(如有)
|___ exports              // 按实际用途导出的文件(物料名-尺寸.格式)
|___ preview              // 便于审核的预览图
```

## 注意

- 尽量不把大图直接存入仓库, 可使用图床或压缩后的预览图, 源文件保留在 Figma 中
- 字体需确认商用授权, 不可用不可商用的字体完成设计
