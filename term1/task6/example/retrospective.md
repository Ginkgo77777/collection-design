# 复盘: 收集习惯改进(示例)

## 本次收编暴露的问题

1. task1 收集链接时没有顺手记来源与截图, 4 条链接失效后无从回溯
2. task2/task4 的字体与图片分散在 Figma 与本地, 没有统一记录授权
3. task5 的 Prompt 与 AI 生成物混在聊天记录里, 收编时翻找很久
4. 大量文件命名为"最终版""新", 归一化耗时最长

## 改进习惯(后续执行)

1. **收集即记录**: 任何资产入库前先填来源与授权, 不确定的进 Inbox 而非默认可用
2. **聊天记录即文档**: AI 对话结束后当天导出关键 Prompt 与结论
3. **命名从创建时开始**: 新建文件即按 `类型-名称-版本` 命名, 不靠事后批量改名
4. **每任务收编**: 每个任务结束后做一次 15 分钟收编, 而不是攒到 task6 一次性处理
