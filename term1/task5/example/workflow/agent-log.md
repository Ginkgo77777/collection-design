## 失败案例与结论

每轮在表格后补充关键输入、修改文件及固定 Commit 链接、命令输出摘要、人工接受 / 修改 / 拒绝理由，并链接 [浏览器验证](validation.md) 的对应记录；完整日志可放个人仓库固定版本路径，只保留与任务有关的内容。视觉偏差链接 Figma 节点或标有版本的小图。

- 问题: 只给参考截图时，Agent 将固定像素值散落在多个组件中。
- 处理: 先补充 Design Token 与组件边界，再要求集中变量并逐页复测。
- 人工验收: 记录实际浏览器、视口、测试内容、偏差与修复结果，而不是只写“已完成”。
