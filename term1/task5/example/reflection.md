# 心得体会(示例)

## AI 工作流的实际价值

- 外化隐性经验: 把我"看排版不顺眼"的直觉拆成了网格、字距、对比度等可检查项, 写进 Skill 后每次都能稳定执行
- 减少重复劳动: 横幅的明暗两版、多尺寸适配由流程自动完成, 我只做审美判断
- 跨轮次一致性: 同一 Skill 在不同文章上产出的风格差异远小于直接 Prompt

## 局限与教训

- 上下文与模型差异: 同一 Skill 在不同模型下的表现有波动, "模型无关"不能只看 README 宣称
- 错误被流程化放大: 模板一旦有错(如字号阶写错), 所有输出都会错, 必须保留人工验收环节
- 审美趋同: 用过几个高星 Skill 后, 输出开始"长得很像", 风格化拆解要保留自己的判断
- 权限风险: 运行第三方 Skill 前不检查依赖与修改范围, 可能被诱导执行不必要的高风险操作

## 风格化与版权边界

- 风格应拆为构图、字体、色彩、形状、材质、动效等可执行规则, 而不是"生成某种风格"
- 参考 → 提炼 → 迁移 ≠ 模仿: 对在世创作者风格的简单模仿存在侵权风险, 不可进入最终交付
- AI 生成的字体/图片/文案需检查来源与授权, 无法确认时一律弃用

## 总结

直接 Prompt < 他人 Skill < 优化后的 Skill ≈ 自研 Skill(按任务匹配程度)。

- 快速探索用直接 Prompt; 稳定交付用 Skill; 高频反复的场景才值得自研或深度优化
- 最终判断永远在设计师: AI 只负责"做得多而快", 不负责"做得对"
