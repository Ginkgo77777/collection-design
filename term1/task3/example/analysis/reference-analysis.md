## 主题拆解记录

| 要素 | 参考主题的处理 | 我的还原方式 |
| --- | --- | --- |
| 正文字号 | 15px, 行高约 1.75 | CSS 变量 `--md-font-size` / `--md-line-height` |
| 标题 | 一级居中, 二级带左侧蓝色竖线 | `h1 { text-align: center }`, `h2 { border-left }` |
| 强调 | 强调文字直接使用主题蓝 | `strong { color: var(--md-accent) }` |
| 引用 | 浅灰底 + 左侧竖线 | `blockquote` 背景与边框 |
| 分隔线 | 中心短线 + 两侧细线的装饰图 | 重构为可编辑 SVG `divider.svg` |
| 图片说明 | 图片下方小号灰色斜体 | 临摹版用 `p em:only-child`(重设计版改为专用类) |
| 文末信息 | 居中灰色小字 | `footer` / `.post-footer` |

## 原主题的不足(重设计依据)

1. 行高 1.75 对手机端长文偏紧, 长段落易疲劳
2. 二级标题的左侧竖线在小屏(320px 宽)上挤压正文空间
3. 大块浅灰底引用块在低亮度屏幕下刺眼
4. 图片说明依赖"仅含斜体"的偶然结构, 换文章就不稳定
