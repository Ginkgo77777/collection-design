# 环境配置与工作记录

## 环境

| 项 | 值 |
| --- | --- |
| 系统 | Windows 11 |
| Node.js | v22.x |
| 包管理器 | npm |
| 部署方式 | `@doocs/md-cli` 本地运行 |

## 启动步骤

```bash
npm i -g @doocs/md-cli
md-cli
# 访问 http://localhost:8800
```

## 遇到的问题与解决

1. **端口冲突**: 8800 被占用, `md-cli port=8899` 指定端口解决
2. **分隔线显示为普通横线**: 参考主题的分隔线是装饰图而非 `hr`, 最终用可编辑 SVG 替换, 记录于主题资产目录
3. **图片说明样式丢失**: 参考文章图片说明是"居中灰色小字", 我最初用 `p em:only-child` 选择器, 遇到"段落中既有强调又有说明"时失效, 重设计主题改为专用类 `.img-caption`
4. **Draft API 凭据**: 未写入仓库, 使用环境变量 `WX_DRAFT_TOKEN`(占位), 已在 `.gitignore` 中排除 `.env`

## 两阶段对照结论

- 临摹版: 还原度高, 但长文可读性与小屏表现一般
- 重设计版: 行高与段间距放宽、标题改用字重与短横线、引用块改左侧粗线, 320px 与 375px 两种宽度下无横向溢出, 长标题换行正常
