# task1 审美积累

任务详情: [learn-design/steps/term1/task1.md](https://github.com/west2-online/learn-design/blob/main/steps/term1/task1.md)

## 提交内容

任选领域、任意数量的任意作品, 用 Markdown 格式记录你对这些作品的:

- **感想**(自身角度): 什么情况看到的这些作品? 对其感觉如何?
- **分析**(专业角度): 这些作品为什么给你这样的感觉? 技法如何? 你认为其考虑了哪些因素? 存在哪些不足?
- **展望**(未来角度): 这些作品给你带来了怎样的启发? 你有怎样的相关思考? 对这些作品的看法是否有所变化?

其他要求:

- 允许插入或引用其他人的感悟, 但需标明出处或给出链接, 并附上你对其感悟的看法与评价
- 尽量不要在没有图床的情况下插入图片, Github 仓库本身并不适合存储大图片
- 字数适中, 能表达出你内心所想即可, 无需堆砌辞藻与案例
- 如果你有个人博客系统, 也可以仅在 README 中给出你的博客链接

