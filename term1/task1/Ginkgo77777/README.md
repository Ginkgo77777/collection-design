## 一些学习感想

最开始我就问过你到底 Git 是什么东西，为什么你们一直用终端敲代码。我不是一个计算机领域的学生，你当时安慰我你以后会告诉我，但是我并不满足于此，这太慢了。

但我没有想到，我居然用了数天的时间才把这一切搞清楚（其实感觉还是没有搞清楚）。先是明白了 Git 的历史、Git 的优势，然后是各种环境的配置，然后才是跟着要求一步一步地完成各种练习。

其实这些我感觉都可以在一天之内搞定，实在都是很容易的小要求。可惜我每次看到一个不懂的术语，都想去习惯性地查一下；每次遇到一个步骤，我都会思考一下为什么这么做。虽然我到了今天晚上的某个时刻，突然感觉到了一些知识的联通，不过真的还是希望此刻的我不要又是一知半解了。

其实配置这些东西都太容易了，让人工智能配置都完全可以，只是我想自己先试一遍，就跟大家第一次代码都是自己敲一样。没想到确实遇到了很多真实的报错问题呢（

甚至即使是写一个简单的 GitHub 主页自我介绍，都碰到了非常多搞笑的问题。这应该是我第一次写终端和用VScode吧，但远程提交成功的那一刻还是很开心的。

**计算机的世界没有魔法，但是获得成就感的那一刻，真的像是被赋予了魔法啊。**

我一直记得25 年 3 月 18 号，你在朋友圈里说总算不再望而却步，虽然疑似那个时候你是一天速通了博客和主页个人介绍吧。

此刻的我有没有离你那时的心境更近一点呢？

但这只是 task1 的开始，我是不会满足于此的，希望接下来的我能够做得更快一点。
